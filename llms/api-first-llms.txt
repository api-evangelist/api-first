# API-First

> API-First is a software development methodology, not a company or a product. It treats APIs as
> first-class citizens: the API contract is designed and agreed before implementation begins, so
> front-end, back-end and third-party teams can build in parallel against one shared reference.
> This is a topic index maintained by API Evangelist. It has no vendor, no domain of its own, and
> no API surface. The platforms listed below are third-party products that support API-first
> practice; each is profiled independently in its own API Evangelist repository.

## Core practices

- **API contracts** — agree endpoint names, request/response schemas, error codes and versioning
  conventions before any code is written.
- **Parallel development** — front-end, back-end and integration teams work simultaneously against
  the contract as the single shared reference.
- **Reusability** — APIs designed first become autonomous, reusable services usable across products.
- **API governance** — style guides, peer review and automated linting keep a portfolio consistent.
- **Developer portal** — an internal inventory, documentation and self-service access surface.

## Where API-first is applied

- Microservices architecture — loose coupling and independent deployment behind stable contracts.
- Headless commerce and CMS — third-party apps and extensions integrate through designed APIs.
- Fintech integration — payment and financial service APIs built contract-first.
- Healthcare interoperability — EHR and clinical APIs designed against HL7 FHIR and peers.
- AI agent integration — discoverable, semantically rich APIs an agent can consume unattended.

## Specifications this practice depends on

- OpenAPI 3.x — the dominant contract format for REST, with tooling for generation, validation and mocking.
- AsyncAPI 3.0 — the contract format for event-driven, WebSocket and message-driven surfaces.
- JSON Schema — the shared vocabulary underneath both.
- Overlay 1.0 — layered, non-destructive enhancement of a spec you do not own.
- Arazzo — multi-step workflow description across operations.
